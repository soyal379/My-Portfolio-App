## 📋 About This Project

Yeh ek modern, responsive portfolio website hai jo React, Tailwind CSS, aur Vite ke saath banaya gaya hai. Isme mera professional journey, skills, projects aur contact information hai.

## ✨ Features

- 🌓 **Dark/Light Theme Toggle** - Choose your preferred theme
- 📱 **Fully Responsive Design** - 100% responsive across all devices
- ⚡ **Fast Performance** - Built with Vite for optimal speed
- 🎨 **Modern UI** - Clean and professional design with Tailwind CSS
- 🧭 **Smooth Navigation** - Easy navigation through different sections
- 🚀 **React Powered** - Built with the latest React 19

## 🛠️ Tech Stack

- **Frontend Framework:** React 19
- **Styling:** Tailwind CSS 4
- **Build Tool:** Vite
- **Routing:** React Router DOM
- **Icons:** Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/soyal379/My-Portfolio-App.git
cd My-Portfolio-App
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
